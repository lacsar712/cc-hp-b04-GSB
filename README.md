# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

可写账号带身份字段（学员 / 师傅），落地页顶栏挂了「带教草稿」链。学员只能建草稿：填饮片、温度、时长，不落正式行；师傅打开草稿点定稿，定稿后才生成正式行并销掉草稿。质检员能看草稿列表，不能建草稿、不能定稿。

## 启动

```bash
cd projects/14-herb-process-record
docker compose up --build
```

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 把 processor 标为学员，建一条白芍草稿：总表行数不变，带教草稿里多一条。
3. 学员身份直接点定稿，应失败（仅师傅可定稿）。
4. 改标为师傅后定稿：总表多一行，草稿消失。
5. 师傅身份再写一条温度 200 的清炒，结论仍是未放行。
6. checker 能看草稿列表，但看不到写入和定稿按钮。
