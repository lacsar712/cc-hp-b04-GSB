# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3193 |
| 接口 | http://localhost:8193 |
| PostgreSQL | localhost:54393 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| processor | herb123456 | 可写（炮制员，可在带教草稿页切换 学员/师傅 身份） |
| checker | check123456 | 只读（质检员） |

## 带教草稿：学员建草稿，师傅定稿

- 可写账号 processor 带一个**身份**字段，取值 `apprentice`（学员）或 `master`（师傅），由前端顶栏切换、请求以 `X-Identity` 头传给后端。
- **学员**只能建草稿：填饮片、清炒温度与时长，写入 `drafts` 表，**不落正式行、不进总表**，也不能定稿。
- **师傅**打开草稿点「定稿」：定稿后才生成正式行（此时判定放行）并销毁草稿；师傅也可在总表直接写正式记录。
- **质检员**可查看草稿列表，但不能建草稿、不能定稿。
- 顶栏挂「带教草稿」入口，落地页含身份切换说明、草稿列表与定稿区。总表是正式行列表，**不设草稿状态列**。

## 启动

```bash
cd projects/14-herb-process-record
docker compose up --build
```

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. processor 以**学员**身份在带教草稿页建一条白芍草稿：草稿出现在草稿列表，但总表行数不变。
5. 学员身份直接点「定稿」返回失败（403）。
6. 切换为**师傅**身份后点「定稿」：总表多一行白芍（放行），草稿从列表消失。
7. checker 可进入带教草稿页查看草稿列表，但看不到建草稿表单与定稿按钮。
